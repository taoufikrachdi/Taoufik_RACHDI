# Taoufik Rachdi — Portfolio

Personal portfolio of **Taoufik Rachdi**, Test Bench Engineer (Test Bench Design & PCB Development) at SERMA Group — aeronautical equipment.

Live: https://taoufikrachdi.github.io/Taoufik_RACHDI/

## Stack
Plain HTML, CSS and JavaScript — no framework. Fonts from Google Fonts, icons from Bootstrap Icons, contact form via Formspree.

## Structure
- `index.html` — page content
- `css/styles.css` — theme (PCB-inspired dark design)
- `js/scripts.js` — nav, scroll reveal, animated test console, contact form
- `assets/` — photos, CVs, certificates

## Run locally
Open `index.html` in a browser.
